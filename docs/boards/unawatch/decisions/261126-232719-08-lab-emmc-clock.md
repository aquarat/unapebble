# The Lab's eMMC on HSI48, B's PLL1 Q applied at runtime

- Status: Accepted
- Date: 2026-11-26 23:27 UTC
- Decided by: agent

## Context
B gives the eMMC PLL1 Q at 80 MHz, set at boot. The Lab boots with A's clock
tree, which has no PLL1 Q, and the mux of the eMMC's kernel clock is what
the bootloader left.

## Decision
The Lab's tree selects ICLK on HSI48 for the eMMC, which only runs while the
card does: 24 MHz at default speed, 48 MHz in High Speed. "B's clocks" applies
B's at runtime: the CPU to MSIS, PLL1 off, set up with Q at 80 MHz and
started, the CPU back on PLL1 R, the eMMC on ICLK = PLL1 Q, the driver's
kernel clock read again. "eMMC on HSI48" goes back.

## Consequences
The eMMC experiments run on either clock; running them on both tells a
clock problem from another. B's clocks stay until the next boot.
