# Build in a multi-arch Docker image

- Status: Accepted
- Date: 2026-11-26 13:06 UTC
- Decided by: owner (containers); agent (image design)

## Context
The owner wants toolchains in containers, not on the shared hosts. Upstream's
CI image is amd64 only, while the Forgejo runners and the development host
are arm64. Recorded after the fact.

## Decision
`docker/Dockerfile` builds `unapebble-build` on Ubuntu 24.04 for arm64 and
amd64, with the PebbleOS SDK 0.1.17 (checksums pinned per architecture) and a
Python venv. `docker/setup.sh` holds the install steps and is run by both the
Dockerfile and CI, so they can't drift. `docker/build.sh` runs builds as the
caller's UID, at low CPU priority (`batch.slice`).

## Consequences
Nothing beyond Docker is needed on a host. An SDK bump means editing the
version and both checksums in `setup.sh`.
