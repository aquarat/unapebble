# Install through UNA's bootloader with our own .ota packer

- Status: Accepted
- Date: 2026-11-26 13:06 UTC
- Decided by: agent

## Context
The stock bootloader installs `.ota` files from the eMMC update drive. The
format is a 64-byte header with CRCs and an AES-256-CBC payload under a key
and IV shared by every watch and published in UNA's kernel repository. There
is no signature. Keeping the stock bootloader keeps the way back to UNA's
firmware. Recorded after the fact.

## Decision
`tools/una/pack_ota.py` builds `.ota` files byte-identical to UNA's packer.
The shared key is committed as `tools/una/SecurityKeys.pem`.

## Consequences
No probe is needed to install or to go back: hold power for 4 s at power-on
for the bootloader menu. The key is public already, so committing it exposes
nothing new.
