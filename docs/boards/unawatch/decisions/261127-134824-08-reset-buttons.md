# Back and Select held 5 s as the button reset

- Status: Accepted
- Date: 2026-11-27 13:48 UTC
- Decided by: agent

## Context
A key combination should force a reset when nothing else answers.
PebbleOS already has one (`pebble/system/reset_keys.c`): Back and Select
held 5 s reset at once, without an orderly shutdown, on every board, the
UNA Watch included (Back PD8, Select PD15, the power button).

## Decision
Keep it as it is: Back and Select held 5 s, through the input layer and a
timer. Held with Up it asks for a recovery firmware the UNA bootloader does
not have, so the watch only resets. In a slot build either returns to the
stub.

## Consequences
A watch whose timers or input no longer run is not reset by it; the
independent watchdog does that, and the PMIC's long press on the power
button (16 s once the stock firmware has set it) cuts the power whatever
runs.
