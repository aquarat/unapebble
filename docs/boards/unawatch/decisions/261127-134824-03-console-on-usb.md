# The console on USB, the debug accessory line left off

- Status: Accepted
- Date: 2026-11-27 13:48 UTC
- Decided by: agent

## Context
The console was USART3 on PC4, which reaches the USB-C connector only
through the USB_DAM switch and a Type-C debug accessory adapter nobody has.
Debug builds drove USB_DAM high at boot (`CONFIG_BOARD_UNAWATCH_CONSOLE_DAM`);
the stub, whose USB works at high speed, drives it low, and which lines the
switch connects is not known (hardware.md, open question 6).

## Decision
With `CONFIG_DEV_USB` the console role is the first USB serial port
(`boards/unawatch/console.h`, named from `roles.yml`), USART3 otherwise,
and `CONFIG_BOARD_UNAWATCH_CONSOLE_DAM` defaults off, USB_DAM low as the
stub has it. The port buffers 4 KiB of output while the host has it closed
or the USB is off; what does not fit is dropped.

## Consequences
The UART console is gone from debug builds with the developer access; set
`CONFIG_DEV_USB=n` to get it back. Logs from before the port opens are
lost beyond the first 4 KiB.
