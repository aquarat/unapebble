# The stub's screen and buttons

- Status: Accepted
- Date: 2026-11-26 23:23 UTC
- Decided by: agent

## Context
With no console, the screen is the only way to see what the stub is doing,
in particular whether its USB came up. PebbleOS's `jdi_gpio` driver has the
panel's timings from the stock driver.

## Decision
The stub clocks the panel with the same timings and rotation as PebbleOS,
draws its state as text in the unscii-8 font (public domain, from LVGL), and
redraws only when the USB has been quiet, as a frame takes 35 ms. The
frontlight blinks off with each command, as an indicator that needs no
display. Back and Select held 2 s reset the watch, Up starts the slot's
image, Down held at start forces full speed.

## Consequences
A blank screen with a blinking frontlight still says the stub runs and gets
commands. The stub does not touch the haptics, which would need I2C writes
to work.
