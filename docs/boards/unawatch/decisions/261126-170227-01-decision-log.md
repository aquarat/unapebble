# Keep a decision log

- Status: Accepted
- Date: 2026-11-26 17:02 UTC
- Decided by: maintainer

## Context
The port is built by several agents over several sessions. The maintainer asked
for every decision to be documented, timestamped `YYMMDD-HHMMSS-NN`.

## Decision
Decisions are recorded in `docs/boards/unawatch/decisions/`, one file each,
under the rules in its `index.md`. Earlier decisions were recorded after the
fact.

## Consequences
Every agent working on the port adds a record for each decision it makes and
reads the log first.
