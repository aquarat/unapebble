# A bare-metal tethered stub in place of a debug probe

- Status: Accepted
- Date: 2026-11-26 23:23 UTC
- Decided by: maintainer

## Context
The watch has no debug console (the UNA debug adapter is missing) and no SWD
probe, so every experiment on the hardware means building and installing a
whole image through the bootloader menu. The maintainer asked for a firmware that
stays connected to a computer over USB-C and runs experiments on request.

## Decision
`tools/una/tether` holds a small bare-metal stub, not PebbleOS, installed as
an `.ota` at `0x08060000` like any image. It takes the first 128 KiB of
flash (about 21 KiB used) and of RAM; experiments load at `0x20020000`, and
a PebbleOS image can go in a slot from `0x08080000`. Everything is polled;
SysTick only counts time and stops overrunning experiments. It is written to
make no assumption about what the bootloader left running, as PebbleOS's
start-up does.

## Consequences
Experiments become small programs built on the host and loaded into SRAM in
seconds. The stub is a separate code base from PebbleOS, with its own small
drivers (clock, USB, display, I2C, flash); register definitions come from
`soc/st/include/hardware` where PebbleOS has them. See
[tether](../tether.md).
