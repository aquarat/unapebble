# USB IDs and names that tell PebbleOS from the stub

- Status: Accepted
- Date: 2026-11-27 13:48 UTC
- Decided by: agent

## Context
The host tools found the stub by 1209:0001, the pid.codes test ID, or by
the name "UNA Watch tether". PebbleOS's two ports must be told apart from
it and from each other, with one TCP tunnel to the Mac.

## Decision
PebbleOS is 1209:0002 (the next pid.codes test ID), manufacturer
"unapebble", product "UNA Watch PebbleOS", with a 12-digit serial number
folded from the chip's unique ID. The console is interface 0 ("UNA Watch
PebbleOS 0"), the tether protocol interface 2 ("UNA Watch PebbleOS 1").
`tether.py` finds the tether role, the stub's port or PebbleOS's
interface 2, by IDs and interface number on Linux (sysfs) and macOS
(`ioreg`), by name otherwise; `bridge.py` serves the tether role on 4500
and PebbleOS's console on 4501, following whichever appears after a reset;
`console.py` runs a shell command over the console. The INFO reply of
PebbleOS sets `TETHER_INFO_PEBBLEOS` and names "PebbleOS <version>".

## Consequences
Test IDs are for private use only; a product would need its own.
