# Keep PebbleOS storage on the eMMC, in its unused GUI region

- Status: Accepted
- Date: 2026-11-26 17:02 UTC
- Decided by: maintainer (use the eMMC); agent (region)

## Context
Storage in the embedded flash is erased on every install (see
261126-130659-02-storage-in-embedded-flash). The 4 GB eMMC is not touched by
the bootloader's install. UNA's kernel splits it at fixed offsets
(`Libs/Header/Components/flash_diskio.h`): UPD 0-100 MB (update files, read
by the bootloader), SYS 100-200 MB, GUI 200-300 MB, USR from 300 MB (user
files, the USB drive). Nothing in the current UNA kernel source reads or
writes the GUI region; its only mention is a disabled erase in `main.cpp`.

## Decision
PebbleOS's flash partitions (filesystem, debug log, crash dumps and the like)
move to the GUI region, starting at sector 409600 (200 MiB), through an
SDMMC eMMC driver and a layer that presents NOR-style flash on 512-byte
blocks. Before relying on it, the bootloader binary is checked for any
access to that region.

## Consequences
PebbleOS data survives updates, and survives a switch to the stock firmware
and back, unless a future UNA release starts using the GUI region. UNA's
files and update drive are left alone. About 832 KiB of embedded flash is
freed.
