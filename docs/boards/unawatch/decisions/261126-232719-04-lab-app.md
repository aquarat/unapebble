# The Lab app: experiments as steps, each announced before it runs

- Status: Accepted
- Date: 2026-11-26 23:27 UTC
- Decided by: agent

## Context
An experiment may hang or reset the watch, and the maintainer reads only the
screen. Its result is worth most when it shows where it stopped.

## Decision
`CONFIG_APP_LAB` (`pebble/apps/system/lab`) lists experiments. Each is a list
of steps run one at a time from app timers: the step's name goes on screen
and in a boot trace breadcrumb, and 120 ms later, once drawn, the step runs;
its results follow it. An experiment that changes something (clocks, copy,
tests) asks for a second Select first. The app opens at boot on the report
of the run before. Its buffers come from a 96 KiB arena in the firmware's
RAM, in SRAM1 as the eMMC builds' buffers are, rather than the app heap at
the top of SRAM5, so that the SDMMC's DMA reaches them as it reaches theirs.

## Consequences
The maintainer opens the app, picks an experiment and reads the result, scrolling
with Up and Down; Select runs it again. A step that resets the watch is named
on the next boot. The experiments are listed in the board page.
