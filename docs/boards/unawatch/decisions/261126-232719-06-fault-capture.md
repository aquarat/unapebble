# Faults, panics and watchdogs recorded where the run before can be read

- Status: Accepted
- Date: 2026-11-26 23:27 UTC
- Decided by: agent

## Context
PebbleOS keeps a reboot reason in registers 25 to 28, cleared at boot once
logged, and writes core dumps to flash: on B, to the eMMC that may be what
fails.

## Decision
The ARM fault handlers record the first fatal fault (PC, LR, xPSR, SP,
EXC_RETURN, CFSR, HFSR, SHCSR, MMFAR, BFAR, thread, the breadcrumb then)
before they log anything; the panic paths record file, line, LR and message;
a task watchdog stall is in the reboot reason, which the trace keeps as the
next boot started with it. A hardware watchdog reset leaves no handler run:
the reset flags and the last breadcrumb show it. The Lab prints PCs as hex,
to map with `addr2line` and the ELF of the image that ran, delivered with
each image.

## Consequences
Only the first fault and panic of a run are kept: the cause, not what
handling it broke.
