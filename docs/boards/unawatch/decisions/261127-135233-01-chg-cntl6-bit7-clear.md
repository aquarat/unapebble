# Leave CHG_CNTL6 bit 7 clear

- Status: Accepted
- Date: 2026-11-27 13:52 UTC
- Decided by: agent

## Context
The stock bootloader reads CHG_CNTL6 bit 7 at boot: with no charger input,
the bit set and no reset cause latched in RESET_MON, it puts the PMIC into
ship mode, so the watch looks dead until USB is plugged in or the power
button is pressed (hardware.md section 9.6, BL@0x08003D9C). PebbleOS wrote
CHG_CNTL6 = 0x95, bit 7 set, where for the charger bit 7 only selects the
10 kOhm NTC bias, unused with the NTC off. The bootloader clears it again,
so the watch read 0x15 after each boot.

## Decision
PebbleOS writes CHG_CNTL6 = 0x15: the same timers, bit 7 clear, which is
what the bootloader leaves.

## Consequences
A reset on battery can't be taken for a ship-mode request. The charger
registers PebbleOS writes now differ from what the bootloader leaves only in
the charge voltage (4.36 V against 4.40 V).
